2. КОНКРЕТНЫЕ ПРОБЛЕМЫ (стоит исправить)
=====================================================================

2.1. README.md устарел в двух местах
     - Раздел «Status»: говорит «M15 has two requirements left — interface
       scaling and drag-and-drop». Это уже сделано (коммиты b1c92d1, cd4a597),
       PROJECT_MASTER.json §16 обновлён («M15 завершён»), а README — нет.
     - Список фич: «3-band and 10-band equalizer» — расширенный режим давно
       параметрический (8 бегунков), не 10-полосный (MASTER_ISSUES 41).

2.2. scripts/__pycache__/ закоммичен в git
     - Два .pyc-файла лежат в репозитории. Удалить из индекса:
         git rm -r --cached scripts/__pycache__
     - И добавить в .gitignore (строки __pycache__/ и *.pyc сейчас отсутствуют).

2.3. Незакоммиченное изменение Cargo.toml
     - [profile.dev] debug = "line-tables-only" (+15 строк) — рабочее и полезное
       изменение (комментарий внутри объясняет экономию десятков ГБ), но оно
       висит незакоммиченным. Закоммитить.

2.4. repository URL в Cargo.toml — заглушка
     - "https://github.com/cadenza-player/cadenza", при этом git remote в repo
       вообще не настроен. Либо завести удалённый репозиторий, либо убрать поле
       до публикации.

2.5. Нет deny.toml / cargo-deny (cargo-audit)
     - Отложен со времён M0 «пока нет зависимостей». Теперь зависимостей сотни
       (symphonia, cpal, slint, image...). Для M16 (релиз) стоит завести
       deny.toml и добавить шаг cargo-deny в CI.

2.6. CI не проверяет MSRV
     - rust-version = "1.92" объявлен, но ни один джоб не собирает на 1.92;
       channel = "stable" означает «последний стабильный». Если MSRV важен —
       добавить джобу с pin'ом toolchain на 1.92.
