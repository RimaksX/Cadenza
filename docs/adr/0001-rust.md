# 1. Rust as the implementation language

Status: accepted (M0)

## Context

Cadenza is a desktop audio player. It needs a realtime-safe audio thread, predictable
memory use over a 1000–5000 track library, and a single native Windows binary with no
runtime to install.

## Decision

Rust, stable channel, edition 2024. Pinned via `rust-toolchain.toml`.

## Consequences

- No GC pauses in or near the audio callback.
- The audio-thread contract (no allocation, no locks, no IO) is expressible and
  reviewable in the type system; `#![forbid(unsafe_code)]` guards `core`, `ui`, `app`,
  and `testkit`, while `infra` keeps `unsafe` available for realtime and OS interop.
- The whole stack — cpal, Symphonia, rubato, rustfft, lofty, notify, rusqlite, Slint —
  is available natively, so no FFI layer is needed.
- Cost: slower compile times and a smaller contributor pool than C# or C++.
